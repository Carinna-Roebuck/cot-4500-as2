# Interpolation Methods 
This project demonstrates various interpolation methods for approximation:
Neville's Interpolation: Computes interpolated value at a given x.
Newton's Forward Method: Finds polynomial coefficients and approximates value at a given x.
Hermite Polynomial Appoximation: Builds Hermite interpolation matrix.
Cubic Spline Interpolation: Solves for cubic splines and outputs matrices and second derivatives.
